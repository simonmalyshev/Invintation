# Настройка Yandex Cloud Function для формы RSVP

> ⚠️ **Замена Cloudflare Worker.** Cloudflare массово блокируется в России с июня 2025 года.
> Форма отправляет данные в Telegram через Yandex Cloud Function. Токен бота хранится
> в переменных окружения функции и **не попадает в публичный GitHub-репозиторий**.

---

## Шаг 1: Создать Telegram бота и получить токен (если ещё не сделано)

1. Откройте Telegram, найдите [`@BotFather`](https://t.me/BotFather)
2. Отправьте команду: `/newbot`
3. Введите название бота, например: `InvintationRSVPBot`
4. Введите username бота, например: `InvintationRSVPBot` (должен заканчиваться на `bot`)
5. `@BotFather` пришлёт токен — **сохраните его**, он выглядит так:
   ```
   1234567890:AAF1BcC..._example_token
   ```
6. Отправьте боту **любое сообщение** (просто напишите `/start` или "привет")
7. Откройте в браузере ссылку (замените `<TOKEN>` на ваш токен):
   ```
   https://api.telegram.org/bot<TOKEN>/getUpdates
   ```
8. Найдите в ответе `"chat":{"id":123456789}` — это **CHAT_ID**. Сохраните его.
   Если ответ `{"ok":true,"result":[]}` — значит боту ещё не писали, отправьте ещё одно сообщение и обновите страницу.

**Результат**: у вас есть `BOT_TOKEN` и `CHAT_ID`.

---

## Шаг 2: Создать Yandex Cloud Function

### 2.1. Зарегистрироваться в Yandex Cloud

1. Перейдите на [Yandex Cloud](https://cloud.yandex.ru)
2. Нажмите **Создать аккаунт** (если нет аккаунта) или **Войти**
3. Создайте **платёжный аккаунт** — потребуется привязать карту
   > **Деньги списываться не будут**, если не превышать бесплатные лимиты.
   > Для вашей задачи (единицы/десятки запросов в день) лимит не будет превышен.
4. Дождитесь активации платёжного аккаунта (обычно 1-2 минуты)

### 2.2. Создать функцию

1. В меню слева выберите **Cloud Functions** → **Функции**
2. Нажмите **Создать функцию**
3. Введите имя: `invintation-rsvp-proxy`
4. Выберите **Node.js** (runtime)
5. Нажмите **Создать**

### 2.3. Загрузить код функции

1. В открывшемся редакторе выберите **Редактор кода** (вкладка "Редактор")
2. **Удалите** весь код-заглушку
3. Откройте файл [`invintation-yc-function.js`](invintation-yc-function.js) в корне репозитория
4. **Скопируйте** всё содержимое
5. **Вставьте** в редактор Yandex Cloud и нажмите **Сохранить изменения** (или Ctrl+S)

### 2.4. Установить переменные окружения

1. В редакторе функции перейдите на вкладку **Переменные** (или **Variables**)
2. Нажмите **Добавить переменную**
3. Добавьте две переменные:

   | Имя | Значение |
   |-----|----------|
   | `BOT_TOKEN` | ваш токен от @BotFather |
   | `CHAT_ID` | ID чата из Шага 1 |

4. Нажмите **Сохранить**

### 2.5. Опубликовать версию

1. В редакторе нажмите кнопку **Создать версию** (или Deploy)
2. Выберите **service account** — если нет, создайте новый или выберите `Выполнять без сервисного аккаунта` (для простой функции это подходит)
3. Нажмите **Создать**

### 2.6. Получить публичный URL

1. После создания версии перейдите на вкладку **Обзор** (Overview)
2. Скопируйте **публичный URL** функции — он выглядит так:
   ```
   https://functions.yandexcloud.net/<идентификатор_функции>
   ```
3. **Сохраните этот URL** — он понадобится на следующем шаге

## Шаг 3: Вставить URL функции в script.js

1. Откройте [`script.js`](script.js)
2. Найдите строку:
   ```javascript
   var TELEGRAM_WORKER_URL = 'https://super-sun-7ddc.semkamal0000.workers.dev/';
   ```
3. Замените значение на URL вашей Yandex Cloud Function:
   ```javascript
   var TELEGRAM_WORKER_URL = 'https://functions.yandexcloud.net/<идентификатор_функции>';
   ```
4. Сохраните файл и выполните commit + push в GitHub

## Шаг 4: Проверить

1. Откройте сайт в браузере (в том числе с мобильного интернета)
2. Заполните форму (имя, статус, комментарий) и нажмите **Отправить**
3. Должно появиться зелёное сообщение об успехе
4. Проверьте Telegram — должно прийти сообщение вида:
   ```
   🎉 Новый ответ на приглашение!

   👤 Имя: Иван
   📋 Статус: ✅ Буду
   💬 Комментарий: С нетерпением жду!

   🕐 28.05.2026, 11:30
   ```

## Важно: Ping-прогрев функции

При открытии сайта браузер отправляет `ping=1`-запрос к функции, чтобы растормошить её после простоя (холодный старт). К моменту, когда гость долистает до формы, функция уже активна и отвечает мгновенно.

Код функции в репозитории обновлён — он обрабатывает `?ping=1`. При перезаливке кода **не забудьте опубликовать новую версию** (Шаг 2.5).

## Если не работает

**Функция не отвечает (ошибка соединения):**
- Проверьте, что URL скопирован правильно (должен начинаться с `https://functions.yandexcloud.net/`)
- Откройте URL в браузере — должен вернуть `callback({"success":false,"error":"Name is required"})`

**Ошибка 403 Forbidden:**
- Функция может быть приватной. Нужно сделать её публичной:
  1. В консоли Yandex Cloud перейдите в функцию → **Настройки** → **Права доступа**
  2. Добавьте роль `functions.functionInvoker` для группы `All users` (все пользователи)
  3. Сохраните

**Сообщение не приходит в Telegram:**
- Проверьте переменные окружения в Yandex Cloud (раздел Функции → Переменные)
- Убедитесь, что `CHAT_ID` — число (без кавычек)
- Ещё раз откройте `https://api.telegram.org/bot<TOKEN>/getUpdates` — проверьте, что боту писали

**Ошибка "Telegram API error":**
- Проверьте, что `BOT_TOKEN` правильный
- Проверьте, что `CHAT_ID` правильный

## Бесплатные лимиты Yandex Cloud Functions

| Ресурс | Бесплатный лимит в месяц |
|--------|------------------------|
| Вызовы функций | 1 000 000 запросов |
| Вычислительное время | 10 000 ГБ × секунда |
| Исходящий трафик | 5 ГБ |

Для свадебного сайта (несколько десятков запросов в день) этих лимитов хватит с большим запасом.
